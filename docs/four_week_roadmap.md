# 四周执行路线：息肉分割的跨数据集泛化与可视化

制定日期：2026-10-20。本文是后续执行建议，不代表训练、外测或系统已经完成；现有研究协议见 `study_plan.md`，正式实验前将接受的配置同步到该协议。

建议题目：《面向跨数据集泛化的结肠镜息肉分割方法与可视化分析系统》。

## 起点与目标

当前已有 Kvasir-SEG 的 1000 对图像和掩膜、数据检查脚本、800/100/100 图像级暂定划分和 CPU 数据读取检查。此处为路线制定时的起点。2026-10-20 已完成启发式近重复筛查、重新划分冻结、U-Net 管线与短程试跑，短程实测见 `day2_report.md`。2026-10-21 又完成 U-Net 三种子各 100 轮正式基线及验证结果验收，见 `baseline_report.md`；CVC-ClinicDB 仍未取得，官方申请路径已整理为 `cvc_access_request.md`，患者/视频分组仍缺失。

2026-10-23 更新：A/B/AB 的实现、15 项单元测试、B 过拟合、AB 断点恢复、三次 5 轮试跑及产物核验已通过；正式九次训练已在 GPU 0 后台串行启动。协议与状态入口见 `ablation_runbook.md`。当前尚无完整消融结论，PraNet、外部数据及最终测试仍待完成。

核心问题：

1. 仅在 Kvasir 训练的模型，内部测试和外部数据集的表现有何差异？
2. 模拟成像变化的数据增强，是否改善外部表现？
3. 增加边界监督，是否改善轮廓质量？与数据增强组合是否有互补收益？

这些都是待验证假设。模块组合不自动构成原创方法，负结果也应完整报告。不同测试集的差异还包括难度和标注习惯，不能把性能差值全部解释成设备差异。

## 范围与优先级

- 必做：U-Net、PraNet、一个固定骨干上的两因素消融、3 个训练种子、至少一个独立外部数据集、错误分析、可运行的本地演示。
- 正常进度下增加：U-Net++ 对比；ETIS 或另一独立来源作为第二外部测试集，先核实获取途径、条款及重叠情况。
- 余力扩展：模型间分歧可视化、推理优化、视频逐帧演示。预测分歧不能直接解释成正确率或临床风险；静态图像实验不能证明视频能力。

主线先完成静态二值分割，不把良恶性判断、自动诊断文本或基础模型微调纳入四周交付。

## 数据与评估协议

仅 Kvasir 的训练部分用于训练；验证部分用于选配置和 checkpoint。内部测试及所有外部测试集在协议和模型冻结后统一评估。CVC 不参与任何训练或参数选择。

第 3 天设数据检查点：若 CVC 获取仍未解决，继续本地基线，同时核实另一外部数据源。没有有效外部数据时，不交付“已经验证跨数据集泛化”的结论；应调整题目为内部鲁棒性研究，明确其证据范围。不得用模型作者打包数据替代来源和版本审核。

沿用现有划分作为起点，在正式训练前完成近重复审查，必要时按组重建并冻结；没有患者映射时始终注明是图像级划分。避免把不同论文的训练/测试组合混在同一排名中。

主指标为原分辨率逐图 Dice、IoU；补充边界 F1 和推理延迟。边界 F1 的容差、尺度归一化方法和实现版本在正式实验前固定；不声称像素边界误差对应毫米。

报告各训练种子的结果及均值、标准差；样本置信区间与种子间波动分开报告。有视频组时按组 bootstrap；没有分组信息则说明相关性限制。模型差异采用同一批图像的配对比较。

大小分析优先采用训练集前景面积占比的三分位点，并将数值阈值冻结后用于全部测试集，称为相对较小/中等/较大组。现有 <1% 的组在全 Kvasir 中仅有 6 张，可作补充描述，不宜独立支撑强结论。测试集可能仍有极少样本或空组，必须报告样本数。该建议已于 2026-10-20 落实，并同步至 `study_plan.md` 和 `data/splits/freeze.json`；冻结阈值约为 7.8237% 和 17.0280%。

预先定义低照度、模糊、反光等质检规则，盲于预测结果标记。合成扰动压力测试使用预先冻结的强度；它与真实外部数据评估分别报告。

## 方法及消融

先实现 U-Net，基础损失采用 BCE + Dice。

A：在基础几何增强之外，加入受控的亮度、对比度、颜色、模糊及压缩扰动。强度仅通过训练/验证数据确定；所有图像空间变换同步作用于 mask，颜色变换仅作用于图像。

B：从训练 mask 生成轮廓监督，增加辅助边界预测头及边界损失。边界宽度、损失权重、训练输出尺度均固定记录；推理可只保留分割输出。该方法是工程实验设计，效果有待验证。

| 配置 | 用途 |
| --- | --- |
| U-Net | 基础参照 |
| U-Net++ | 架构对照，进度紧张时先删减 |
| PraNet | 息肉分割领域参照 |
| U-Net + A | 检验成像增强 |
| U-Net + B | 检验边界监督 |
| U-Net + A + B | 检验组合效果 |

完整方案为 6 个配置 × 3 个训练种子 = 18 次正式训练；删减 U-Net++ 后为 15 次。小规模调试和验证集调参不计入正式结果。消融使用相同骨干、初始化策略、训练预算及其余配置。跨架构比较明确参数量、预训练来源和预算差异，不把预训练优势误认为结构优势。

不加载用评估数据训练过的息肉模型权重。PraNet 采用作者代码作为实现参考，但按本项目的数据协议重新训练；需要核实版本、许可及通用骨干权重来源。若改变原论文的训练损失或流程，标记为统一协议下的适配实验。

起始调试配置建议：352×352 输入、AdamW、学习率 1e-4、BCE + Dice、混合精度；先尝试 batch size 8，再据实际显存决定。缩放采用一种明确的策略，记录其几何影响。正式 epoch 上限和早停策略由试跑耗时与验证曲线确定，在查看测试结果前冻结。

## 四周安排与验收

| 时间 | 工作 | 可检查的交付 |
| --- | --- | --- |
| 第 1 周 | 数据审查；训练/评估骨架；U-Net；外部数据获取 | 小批量过拟合检查通过；能训练、存取权重、验证和推理；有基线验证曲线 |
| 第 2 周 | PraNet 与可选 U-Net++；A/B 模块；验证集调试 | 配置与实现版本登记；正式实验清单和预算冻结；演示界面初版 |
| 第 3 周 | 多种子正式训练；冻结后统一测试；消融及错误分析 | 完整结果表、逐图指标、置信区间、大小/质量分组、固定规则选出的成功和失败案例 |
| 第 4 周 | 系统集成；报告和答辩材料；复现检查 | 本地演示、权重、配置、启动说明、论文图表和演示录像 |

第 1 周末仍未跑通基线时，删除 U-Net++ 和额外数据集扩展。第 2 周末仍未稳定时，优先完成 U-Net/PraNet 和单一改进的消融。第 3 周完成统一外测后不继续按外测分数调参；后续改动标记探索性，不能沿用同一外测声称独立确认。

训练预算先通过 5–10 个 epoch 试跑估算，记录每个模型的秒/epoch、峰值显存与收敛情况，再计算总 GPU 小时。按服务器实际空闲资源安排，单次训练先用一张卡。

## 演示系统

最低交付支持上传原图、选择已训练模型、显示概率图/二值掩膜/透明叠加、下载结果和查看推理耗时。上传真实标注后才计算 Dice/IoU；没有标注时不显示“准确率”。面积占比只代表图像像素比例。

增加固定样例的多模型并排比较和实验结果页，使演示能解释研究发现。默认本地运行；页面注明课程研究原型。性能测量区分模型前向耗时和完整预处理/后处理耗时，GPU 测量须预热并同步。
