# 结肠镜息肉图像分割的跨数据集泛化：研究方案

**问题与范围。** 仅用 Kvasir-SEG 训练时，分割模型在独立来源 CVC-ClinicDB 上相较内部测试的 Dice/IoU 会下降多少？这种变化是否集中于小息肉和低质量画面？本工作是研究原型，不声称方法创新或临床有效性，不用于诊断。

**数据与划分。** Kvasir-SEG 为主要训练域（Jha et al., MMM 2020）；CVC-ClinicDB 为外部测试域（Bernal et al., CMIG 2015）。官方来源、条款及可用性见 `data_sources.md`。Kvasir 按固定种子 20261019，目标 80/10/10 分为训练/验证/内部测试；优先用发布方患者 ID，次选视频 ID 分组；若未能获得分组映射，明确将当前划分标记为图像级暂定划分，并将精确重复图像归同组，不能声称患者独立。2026-10-20 已通过 pHash/dHash 与中央区域相关性筛查，将 40 对高优先级候选保守归组并重新划分，仍为 800/100/100；候选不全是真重复，广泛筛查仍有 398 对跨集合候选，不能宣称已彻底排除近重复。列表与校验和已冻结于 `data/splits/freeze.json`。CVC 全部保留为外部测试；当前缺少官方可用下载，尚未完成外部数据核验。

**比较与公平性。** 首先实现标准 U-Net 基线，再比较 U-Net++ 和面向息肉分割的 PraNet；具体版本、许可证和实现需训练前核实。统一数据划分、输入处理、训练预算及评估代码。预训练权重来源必须登记，排除使用相关息肉数据预训练的权重；从头训练与通用预训练分别报告。仅 Kvasir 训练子集提供增强及统计量，验证集用于学习率/损失/早停/阈值决策。建议 BCE+Dice 损失，至少 3 个训练随机种子；短程试跑配置见 `configs/unet_pilot.json`：352×352 直接缩放、batch 8、基础通道 32 的自实现 U-Net、无预训练、AdamW（学习率/权重衰减均 1e-4）、水平/垂直翻转、AMP；种子 20261020，先 5 轮再恢复 1 轮。该配置用于管线和预算检查，不等于正式训练协议已冻结；2026-10-20 已另行冻结并启动正式 U-Net 基线 v1：种子 20261020/20261021/20261022，分别从头训练固定 100 轮、不早停、常数学习率，按验证 Dice 选最佳轮；这是预算约定而非收敛证明。该批次于 2026-10-21 完成并通过结果核验，详见 `baseline_report.md` 和 `baseline_runbook.md`。其余模型和最终测试协议仍待冻结。

**两因素消融执行状态（2026-10-23）。** 在同一 U-Net 上增加训练图像成像扰动 A、辅助边界监督 B，以及 AB；参数、随机数隔离、边界定义和验收详见 `ablation_runbook.md`。三条件各 5 轮试跑及工程检查通过后，已冻结 `configs/unet_ablation_protocol.json` 并启动九次正式训练：每条件沿用基线三个种子，各从头训练 100 轮，其余预算和评估规则一致。A/B 参数未按短程分数修改。完成后报告条件内均值、样本标准差、配对种子差值和交互项；这些仍是验证集上的配置研究，内部与外部测试继续封存。

**指标。** 在原始分辨率将概率图双线性恢复，再使用冻结阈值（默认 0.5）二值化；真值读取时灰度 >=128，缩放只用最近邻。逐图计算 Dice=2TP/(2TP+FP+FN)、IoU=TP/(TP+FP+FN)，以逐图宏平均为主要结果，并报告中位数、离散度及置信区间；空真值且空预测记 1，空真值但非空预测记 0。主面积分组已于拟合前按新的 800 张训练图原始真值前景面积占比三分位冻结：相对较小 <0.07823705480251435，中等 [0.07823705480251435, 0.17028016362068238)，较大 >=0.17028016362068238。各组报告样本数及 Dice/IoU；这是图像面积分组而非毫米大小或临床分级。原先 <1%、1%–5%、>5% 的固定分组仅保留为历史预案，未作为当前管线的主分析。补充边界 F1 使用内侧 8 邻域轮廓，图外视为背景，Chebyshev 距离容差为 max(1, floor(0.005×原图对角线+0.5)) 像素。无样本的组报告 N/A。多息肉图像使用前景总面积，该定义不等同于单病灶大小。

**外部测试。** 冻结配置、代码版本、所有种子的最佳验证 checkpoint、阈值与后处理后，再一次性运行内部和外部测试；不按外测表现挑模型或种子。只做事先规定的数据完整性检查，不用外部图像指导增强或超参数。记录各模型外部绝对表现及相对内部下降。利用官方视频分组进行序列 bootstrap（同患者多序列仍可能相关）；无患者/视频映射的 Kvasir 图像 bootstrap 必须注明独立性假设不足。后续据外测错误改进的方法须标记为探索性，并用新独立数据重新确认。

**错误分析和局限。** 预先定义模糊、反光、低照度、遮挡等多标签质检规则，盲于模型输出执行；自动清晰度/亮度代理不等于临床质量。外测后的叠加图分析仅为解释，不用于调参。风险包括近似帧、相同患者、跨库重复、预训练污染、尺度变形、JPEG mask 边界噪声、设备/中心域差异、标注习惯差异以及小样本不确定性。图像文件名不能推断患者身份；精确哈希检查不能排除近重复，需在训练前完成独立相似帧审查。仅包含息肉的静态图像不能验证无息肉场景的假阳性、视频实时性能或临床获益。两域也不能代表所有医院/人群。
